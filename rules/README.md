# Règles YARA du cours

Mettre ici les règles fournies avec le TP2 (`course_rules.yar`) : `poetry run tp2` lit par défaut les
`.yar` / `.yara` de ce dossier (ou celui donné par `--rules`).

Nos propres règles sont dans `src/tp2/utils/rules.py` et sont toujours ajoutées : l'archive rendue ne garde
pas les fichiers `.yar`.
